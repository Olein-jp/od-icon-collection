WordPress標準のアイコンライブラリに4コレクション、8,696件のアイコンを追加します。

== Description ==

Feathericon、Font Awesome Free Solid/Regular、Material Symbols Outlined、Lucideを同梱します。
標準のアイコンブロックから選択し、色・幅・配置・回転・反転を設定できます。
アイコン名は英語のまま表示し、翻訳しません。
設定 → OD Icon Collectionでコレクションの有効・無効を切り替えられます。
無効化・削除すると使用済みアイコンが表示されなくなる場合があります。
GitHub Releasesのod-icon-collection.zipをインストールしてください。
同梱素材のライセンスと改変はTHIRD-PARTY-NOTICES.mdを参照してください。
